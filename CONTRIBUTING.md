# Contributing to Launch Loop

Thank you for helping. Launch Loop is a set of skills (instructions written in plain text) for Claude, Codex, and other tools that follow the Agent Skills format. You do not need to be a programmer to help.

## Ways to help

- **Try a skill and tell us what happened.** Open an issue and say what you asked, what the skill did, and what you expected. This is the most useful kind of help.
- **Report a mistake or unclear sentence** in a skill or in the README.
- **Suggest an improvement.** Describe the problem first, then your idea.
- **Improve a skill.** Edit the `SKILL.md` file and open a pull request.

## Before you open a pull request

1. Keep one change per pull request.
2. The folder name of a skill must match the `name` in its `SKILL.md` header.
3. The `description` in the header must stay under 1024 characters.
4. Keep skills short and in plain English. Every skill replies in the user's language, so keep the "Language" section.
5. Skills must never push, post, close, or delete anything without the user's approval. Please do not weaken these rules.
6. Never include real secrets, private project details, or screenshots of private code in examples.

## Security problems

Do not open a public issue for a security problem. See [SECURITY.md](SECURITY.md).
