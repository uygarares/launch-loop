# Security Policy

Launch Loop is made of text instructions, not running software. Still, a badly written skill could cause an assistant to do something unsafe (for example, post or delete something without asking).

## How to report a problem

Please do not open a public issue for a security problem.

Use GitHub's private reporting: open the **Security** tab of this repository and choose **Report a vulnerability**.

Please include which skill is affected, what you asked the assistant, and what it did.

## What to expect

This is a small project run by one person. We will read your report as soon as we can, tell you what we decide, and credit you if you want.

## Supported versions

Only the latest version on the `main` branch is supported.
