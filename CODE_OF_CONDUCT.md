# Code of Conduct

Launch Loop is for people at every level, including people who have never used GitHub before. Please help keep it welcoming.

## What we expect

- Be kind and patient, especially with beginners.
- Disagree with ideas, not with people.
- Assume good intentions and ask when something is unclear.
- Respect other people's time. Maintainers work on this project in their free time.

## What is not accepted

- Insults, harassment, or personal attacks.
- Discriminatory language or jokes.
- Spam, advertising unrelated to the project, or fake accounts and fake activity.
- Sharing other people's private information.

## What happens

Comments, issues, or pull requests that break these rules can be edited, hidden, or removed, and repeat offenders can be blocked.

## How to report a problem

Contact the maintainer through the contact options on the profile of [uygarares](https://github.com/uygarares). Please do not use a public issue for this. For security problems in the project itself, see [SECURITY.md](SECURITY.md).
